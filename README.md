# MahdiFit Hub

يتضمن النظام إدارة كاملة للعضويات عبر MVC: عرض الاشتراكات، إنشاء عضوية، حساب تاريخ الانتهاء والسعر، الإلغاء، التجديد، ومنع حجز الحصص دون عضوية فعالة.

نظام عربي أصلي لإدارة نادٍ رياضي، مبني باستخدام ASP.NET Core MVC على .NET 10 مع تخزين JSON محلي خفيف.

## الميزات

- تسجيل دخول آمن باستخدام Cookie Authentication وتجزئة كلمات المرور.
- أدوار منفصلة: مسؤول، مدرب، وعضو.
- لوحة متابعة لإحصاءات الأعضاء والمدربين والحصص والحجوزات.
- إدارة الحسابات وتفعيلها أو إيقافها.
- إدارة باقات الاشتراك ومدتها وسعرها وحدود الزيارات.
- جدولة الحصص مع المدرب والقاعة والسعة.
- حجز وإلغاء الحصص مع منع الحجز المكرر أو تجاوز السعة.
- واجهة عربية متجاوبة من دون اعتماد على مكتبات Frontend خارجية.
- مخزن بيانات JSON محلي يُنشأ ويُملأ ببيانات تجريبية تلقائيًا عند التشغيل الأول.

## متطلبات التشغيل

- .NET 10 SDK

## التشغيل

```powershell
dotnet restore
dotnet run
```

ثم افتح `https://localhost:7188` أو الرابط الذي يظهر في الطرفية.

## حسابات التجربة

| الدور | البريد | كلمة المرور |
|---|---|---|
| مسؤول | `admin@mahdifit.local` | `Admin123!` |
| مدرب | `trainer@mahdifit.local` | `Trainer123!` |
| عضو | `member@mahdifit.local` | `Member123!` |

غيّر الحسابات الافتراضية قبل أي استخدام فعلي. لحذف البيانات التجريبية وإعادة إنشائها، أوقف التطبيق واحذف ملف `App_Data/mahdifit.json` ثم شغّله مجددًا.

## بنية المشروع

- `Controllers/`: منطق الطلبات والصلاحيات.
- `Data/`: مخزن JSON المتزامن وتهيئة البيانات.
- `Models/`: كيانات المجال ونماذج الإدخال.
- `Views/`: صفحات Razor العربية.
- `wwwroot/`: التصميم المتجاوب الخاص بالمشروع.

## ملاحظات أمنية

- لا توجد مفاتيح API أو كلمات مرور إنتاجية داخل الإعدادات.
- جميع العمليات المعدّلة تستخدم Anti-forgery tokens.
- تُكتب البيانات بأسلوب ذري إلى ملف محلي مع قفل تزامن لمنع التعارض.
- ملف قاعدة البيانات مستثنى من Git.
